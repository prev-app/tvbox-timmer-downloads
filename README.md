# TVBox Timmer · Descargas

Sitio público de descarga de TVBox Timmer, desarrollado por PREVAPP.

- Página: `https://prev-app.github.io/tvbox-timmer-downloads/`
- Versión actual: **2.2**
- Contacto: prevapp.contact@gmail.com

La versión 2.2 puede instalarse normalmente sobre la 2.1 y conserva su
configuración. Quienes todavía tengan instalada la versión 2.0 deben
desinstalarla antes de instalar la 2.2.

La aplicación consulta `version.json` para comprobar nuevas versiones y
verifica la huella SHA-256 del APK antes de abrir el instalador de Android.

El código fuente de la aplicación se conserva en un repositorio privado separado.
